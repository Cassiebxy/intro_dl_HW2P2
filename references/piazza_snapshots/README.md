# Piazza Snapshots

Manual snapshots of HW2P2-related staff posts/clarifications, for offline AI review context.

- **Authoritative live source**: Piazza HW2P2 thread (@301) and linked staff posts (@302 model rules, @303 ArcFace tips) — snapshots here go stale.
- **Main tracking source**: the course-wide 2-day Piazza summary series lives outside this repo (see local `piazza_2days_summary` folder); only HW2P2-relevant staff items get copied here.
- **Update convention**: each snapshot file starts with a header block:

```markdown
> Fetched: YYYY-MM-DD HH:MM ET | From: Piazza @NNN | By: (manual/browser export)
> Status: current / superseded by <file>
```

- **What deserves a snapshot**: new/changed staff clarifications on rules, cutoffs, deadlines, submission mechanics. Student discussion → only if staff-endorsed, and labeled as such.
- **Do not** commit personal data or other students' contact info.
